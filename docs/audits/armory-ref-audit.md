## How to read this

- A `MISSING_BODY` row hangs every mission that preloads a carrier: repoint the item to the art that ships (never restore a tpac beside its replacement), then re-run with `--regen-catalogue`.
- A `MISSING_MESH` row is an invisible item; same fix.
- A deleted or renamed mesh that is still named is tomorrow's row: fix it today.
- New art nothing uses is an audit signal for the roster authors, not a fault.
