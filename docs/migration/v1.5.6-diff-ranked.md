Companion to [v1.5.6-impact.md](v1.5.6-impact.md). This ranks the members TAOM binds: every Harmony
patch target, every GameModel base method TAOM overrides and every reflection site. Bodies were
extracted from `E:\Decompiled_Bannerlord\_shipping_build_v1.5.5` / `_modules_build_v1.5.5` and the

E:\Decompiled_Bannerlord\_diff_1.5.5_to_1.5.6\bound_members` (2026-10-27), and every CHANGED row went
to a review agent with the diff, the TAOM override or patch, and one question: does TAOM
re-implement a term that moved.

## The engine themes behind the rows

- **Perk API reshape.** `MobileParty.HasPerk` lost both `out Hero` overloads, and
  `PerkHelper.AddPerkBonusFor*` moved `BattleEnvironment` to a trailing optional parameter. Most
  `DefaultXxxModel` bodies changed only in this shape. The new `HasPerk` gate
  (`PerkHelper.TryGetPerkEffectBonus`) behaves like v1.5.5's `ApplicableInEnvironment` for Land, Any
  and Naval too; the only difference is v1.5.5's `None`, which v1.5.6 removed. `MobileParty.CurrentBattleEnvironment` only
  ever reports Land or Naval in both versions.
- **Assert line numbers.** Several rows changed only in the line number inside a `SilentAssert` text.
- **Parley.** Field parley with lord parties reaches the tooltip builders through
  `AddTooltipHintProperties`.
