# RCA: Dale review follow-ups (#949, #950, #951, #952; deep review 2026-10-20)

## Top-line

Six follow-ups from the Dale lord expansion review were built and reviewed together: a `Faction.` reference
gate in the ModuleData validator (#949), a whitespace cleanup of `lords.xslt` (#950), broken clan banner keys
and a banner icon gate (#951), a new-campaign pass that gives every campaign lord a face of their own (#952),
the renown bands in the clan modding guide, and a union merge driver for the lessons files. Eight lenses ran.
No lens found a crash path. The review found 1 HIGH, 11 MEDIUM and many LOW findings; every one was fixed in
the same session. Mike asked to commit mid-way so other sessions could push, so #950, #952 and the docs landed
in `5e45d2782`, `5ceeaa77f` and `4b7e36250` before the validator, banner and hook fixes.

## Patterns

**A gate must say how much it read.** F1 and F5 are both checks that could not fail for the case their message
describes: the banner pattern silently skipped keys, and the fake made every result unique. Counting what a
gate parsed against what exists, and building fakes from the engine's real inputs, makes both visible. The
same lesson was recorded the day before for the culture fallback batch; it repeated here.

**Copy the engine's inputs, not only its call.** F2, F3 and F11: the face pass called the same engine function
vanilla calls, but with a different age, at an earlier moment, and without the body roll vanilla does beside
it.

## Why each agent missed these

The builder wrote tests first but did not run them before the implementation existed, so no RED was observed
(F5). The architect's research traced the roll and the event but not the child generation that follows it
(F3) or the age bucket inside the native roll (F2); the engine lens found the second by decompiling the native
function. The banner gate was written by the orchestrator and checked against the three keys it was meant to
catch, not against the whole file (F1).

## Process note

A read-only XSLT transform started by a review agent at 08:30 hung for more than four hours and held
`spclans.xslt` open, which blocked the colour fix until the process was stopped. Scratch transforms should run
with a timeout.
